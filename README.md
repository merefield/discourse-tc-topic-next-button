# Topic Next Button

Adds a Next topic link to the topic timeline and compact topic navigation. It follows the order of the topic list you opened the topic from and is hidden when there is no next topic.

By default, the link opens the first post. Turn off `topic_next_always_go_to_first_post` to use Discourse's usual topic-list link, which can resume at an unread post. Use `topic_next_categories` to choose which categories show the link. Leave the list empty to show it in every category.
